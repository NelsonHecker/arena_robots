# mpo700

Neobotix MPO-700: 4-wheel swerve, 0.74 x 0.51 m, 140 kg.

Vendored from [neobotix/neo_mpo_700-2](https://github.com/neobotix/neo_mpo_700-2) `robot_model/` (BSD-3, jazzy branch). Meshes live in the `meshes/` submodule.

Driven by `arena_swerve_controller`. Two SICK S300 lidars (front-left + back-right). Sensor xacro shared with rbvogui.
